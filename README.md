# Data Science & AI Internship Projects

## About This Repository
This repository contains five projects completed as part of my Data Science & AI Internship at InternCircle.

## Projects

### 1. Exploratory Data Analysis (EDA) on Titanic
- Analyzed the Titanic dataset using Python and Pandas.
- Identified missing values and survival patterns.
- Explored passenger survival based on gender and class.

### 2. Data Visualization
- Used Matplotlib and Seaborn libraries.
- Created Histogram, Box Plot and Scatter Plot.
- Generated a Correlation Heatmap to understand data relationships.

### 3. Customer Churn / Sales Trend Analysis
- Created a sample sales dataset.
- Calculated total revenue and product-wise sales.
- Identified top customers and analyzed monthly sales trends.

### 4. First Machine Learning Classifier
- Used the Iris dataset.
- Developed a Decision Tree Classifier using Scikit-learn.
- Performed model training, testing and prediction.
- Evaluated model performance using accuracy and confusion matrix.

### 5. Interactive Machine Learning Web Application
- Developed an Iris Flower Prediction App using Gradio.
- Created input sliders for flower measurements.
- Integrated the Decision Tree model with the application.
- Tested the application and generated flower predictions.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Gradio, Joblib and Google Colab.

## Learning Outcomes
Gained practical knowledge of Data Analysis, Data Visualization, Machine Learning, Model Evaluation and Interactive Web Application Development.
